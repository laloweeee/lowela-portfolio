LearnSphere

AI-Powered Learning Analytics System

Overview

LearnSphere is a comprehensive learning analytics platform designed to help educators identify at-risk students and personalize interventions. It uses an XGBoost model to predict student performance from behavioral and academic data, and SHAP (SHapley Additive exPlanations) to make the predictions interpretable and actionable for instructors — not just a black box.

Key Features
  • Predictive analytics engine using XGBoost trained on student engagement, grades, and activity data
  • SHAP-powered explanations visualizing which factors most influence each student's predicted outcome
  • Real-time educator dashboard with drill-down views per student, class, and cohort
  • Automated intervention recommendations based on risk level and identified risk factors
  • Supabase-powered backend with Row Level Security for student data privacy
  • FastAPI RESTful backend serving ML inference endpoints with sub-200ms response times
  • Responsive ReactJS frontend with TypeScript for type-safe UI development
Tech Stack
ReactJS TypeScript TailwindCSS FastAPI Python XGBoost SHAP Supabase PostgreSQL Pandas Scikit-learn

NeoME

Gamified AI-Driven Wellness App

Overview

NeoME is a cross-platform mobile wellness application that makes healthy habits engaging through gamification. At its core is an AI wellness companion powered by Google's Gemini API, offering conversational check-ins, mood analysis, and personalized wellness nudges. Users earn streaks, badges, and rewards for maintaining healthy routines.

Key Features
  • AI-powered wellness companion using Gemini API for natural conversation, mood journaling, and personalized advice
  • Gamified habit tracker with streaks, experience points, badges, and a visual progression system
  • Mood analytics dashboard with historical trends and pattern recognition
  • Personalized wellness recommendations generated from user behavior and mood history via Flask ML backend
  • Firebase Authentication and Firestore for real-time sync across devices
  • Push notifications for habit reminders and wellness check-in prompts
  • Smooth, native-feeling UI built with React Native and Expo for iOS and Android
Tech Stack
React Native Expo TypeScript Flask Python Firebase Firestore Google Gemini API Expo Notifications AsyncStorage
